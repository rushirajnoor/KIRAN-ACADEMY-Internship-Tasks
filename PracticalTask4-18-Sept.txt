============================================================
IMPORTANT SQL RULES FROM THE PRACTICAL
============================================================

1. String and date values must be enclosed in single quotes:
   'Pune'
   'IT'
   '2026-01-10'

2. Numerical values should not be enclosed in quotes:
   35000
   103
   50000

3. NULL values must not be compared using = or !=.
   Incorrect:
   WHERE email = NULL

   Correct:
   WHERE email IS NULL

   Correct:
   WHERE email IS NOT NULL

4. Use parentheses when combining AND and OR to make the intended
   logical precedence explicit.

5. BETWEEN is inclusive of both boundary values.
   Example:
   salary BETWEEN 40000 AND 70000
   includes 40000 and 70000.

6. LIKE wildcards:
   %  = any number of characters, including zero characters
   _  = exactly one character
